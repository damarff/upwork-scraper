# Freelancer.com Scraper

Scrapes Freelancer.com job listings using DrissionPage (Chromium browser automation). Extracts job details, stores in SQLite database.

## Features

- Browser automation with anti-detection
- Job listing extraction and parsing
- SQLite storage
- Headless mode support

## Quick Start

```bash
pip install -r requirements.txt
python scrape_freelancer_drission.py
```
